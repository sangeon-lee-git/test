# 한글 히어로 · 숲속 별빛 대전

50개월 아이와 함께 하는 한글 학습 액션 게임입니다.

- 같은 글자 찾기 / 그림의 첫 글자 찾기
- 돌진 펀치, 회전 킥, 에너지파, 별빛 필살기
- 타격 반동과 효과음, 방패 방어
- 오답 감점과 시간제한 없음, 두 번 오답 후 힌트
- 보호자 설정: 선택지 2/3개, 음성 비교, 부드러운 액션
- 한 판 5문제, 세 판 뒤 쉬기 안내
